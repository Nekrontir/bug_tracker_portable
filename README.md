# Portable Bug Tracker

Небольшой десктопный баг-трекер на Python + Tkinter + ttkbootstrap.

## Возможности

- Создание, редактирование и удаление багов.
- Поля: заголовок, статус, приоритет, версия, заметки, дата создания.
- Фильтрация по статусу и приоритету, поиск по заголовку.
- Вложения:
    - прикрепление файлов к багу,
    - хранение файлов в папке `attachments/<bug_id>/`,
    - просмотр списка вложений, открытие файла или папки,
    - удаление вложений при удалении бага.
- Экспорт и импорт:
    - JSON — только данные багов,
    - ZIP — `bugs.json` + вложения.
- Темы ttkbootstrap, выбор темы из списка.
- Настройки GUI:
    - сохранение выбранной темы,
    - сохранение размера и положения окна,
    - сохранение ширины колонок таблицы.
- Горячие клавиши:
    - `Ctrl+N` — новый / очистить форму,
    - `Ctrl+S` — сохранить изменения,
    - `Delete` — удалить выбранный(е) баг(и),
    - `Ctrl+C` — копировать баг (внутренний и системный буфер),
    - `Ctrl+V` — вставить баг из буфера.
- Массовое удаление по чекбоксам:
    - первая колонка `[ ] / [x]` для выбора,
    - подтверждение удаления,
    - явное предупреждение при наличии вложений.

## Структура проекта

```text
project_root/
│
├─ src/
│  ├─ gui.py           # графический интерфейс
│  ├─ service.py       # логика багов, импорт/экспорт, работа с вложениями
│  ├─ models.py        # модель Bug
│  ├─ storage.py       # работа с bugs.json
│  ├─ attachments.py   # управление папкой attachments/
│  └─ settings.py      # сохранение/загрузка настроек (settings.json)

├─ main.py             # точка входа
├─ bugs.json           # база багов (создаётся автоматически)
├─ attachments/        # вложения (создаются по мере необходимости)
└─ settings.json       # настройки GUI (создаётся автоматически при закрытии)
```


## Настройки (settings.json)

Файл `settings.json` создаётся автоматически при закрытии программы рядом с exe или основным скриптом [web:233][web:244]. В нём сохраняются:

- `theme` — имя темы ttkbootstrap;
- `geometry` — строка геометрии окна (`ширинаxвысота+X+Y`);
- `tree_columns` — словарь `имя_колонки -> ширина`.

Пример:

```json
{
  "theme": "flatly",
  "geometry": "1050x720+200+100",
  "tree_columns": {
    "Selected": 70,
    "ID": 90,
    "Title": 260,
    "Status": 90,
    "Priority": 90,
    "Version": 80,
    "Created": 110
  }
}
```

При следующем запуске программа читает этот файл и восстанавливает тему, размер/позицию окна и ширины колонок.

## Сборка в exe

Пример для PyInstaller:

```bash
pyinstaller --onefile --noconsole -n PortableBugTracker main.py
```

После сборки:

- `PortableBugTracker.exe` можно положить в любую папку;
- при первом закрытии создастся `settings.json` рядом с exe;
- в той же папке будут создаваться `bugs.json` и `attachments/`.

## Требования

- Python 3.10+
- Библиотеки:
    - `ttkbootstrap`
    - для сборки в exe — `pyinstaller` (опционально)
